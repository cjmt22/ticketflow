# TicketFlow

A multi-tenant helpdesk SaaS where an AI assistant triages support tickets.

> 🚧 Work in progress. Building in public, follow along on LinkedIn.

## Planned features
- Multi-tenant workspaces (each company's data is fully isolated)
- Roles: Admin, Agent, Customer
- Ticket management with search, filters, and status workflow
- AI triage: auto-category, priority, thread summary, suggested reply
- File attachments, real-time updates, CI/CD pipeline

## Tech stack
React · TypeScript · Node.js · NestJS · PostgreSQL · Prisma · Docker · GitHub Actions
